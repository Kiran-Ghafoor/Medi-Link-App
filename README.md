# Medi-Link 🏥💊

Medi-Link is a full-stack medicine donation platform that connects people who have unused, unexpired medicines with those who need them. Built to reduce medicine wastage and improve access to affordable healthcare.

## 🚀 Features

- User authentication (donor & receiver roles)
- Donate unused medicines with details (name, expiry, quantity, condition)
- Browse and request available medicines
- Real-time request/approval system between donors and receivers
- Admin panel for monitoring listings and users
- Responsive UI built with modern design principles

## 🛠️ Tech Stack

**Frontend:** React.js, HTML5, CSS3, Bootstrap/Tailwind  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Other Tools:** Figma (UI/UX prototyping), Git & GitHub, Postman (API testing)
